Aesthetic direction

Tactical minimalism — Webull's data density meets Robinhood's clarity. True black canvas, hairline borders, tabular numbers, single mint accent. Korean color semantics preserved (red = up, blue = down).

No gold, no glass — replaced with one electric accent (#00E5A0) that signals AI/premium without nostalgic wealth tropes.

What changed from current

  • Background: deep navy → true black
  • Primary accent: brass gold → electric mint
  • Type: Archivo → Pretendard + Geist Mono
  • Cards: glass blur → flat surface + 1px hairlines
  • Numbers: condensed sans → tabular monospace
  • Charts/sparklines: every row, every card
  • Headers: smaller, info density up

How to use this

  • Click sidebar items to jump screens
  • Tap KOSPI / US toggle on Market screen
  • Tap stock row → opens detail sheet
  • Bottom tabs are clickable (4 tabs)
  • Open in any browser — no install
